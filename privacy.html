Hypothetical Capital Uploads: Privacy Policy

Last updated: 30 October 2026

Hypothetical Capital Uploads is a private tool used only by the owner of the Hypothetical Capital YouTube channel (https://www.youtube.com/@HypotheticalCapital) to manage that channel.

What it accesses. With the channel owner's permission, it uses the YouTube Data API and YouTube Analytics API to upload the channel's own videos, set their titles, descriptions, thumbnails and publish times, post comments on the channel's own videos, and read the channel's own performance reports.

What it stores. It stores no personal data about viewers or any other users. The only credential it keeps is the owner's access token, held privately in the owner's own environment settings.

Sharing. It does not sell, share or transfer any data to third parties.

Google API Services. Use of information received from Google APIs follows the Google API Services User Data Policy (https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. It also uses YouTube API Services, so it is subject to the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).

Revoking access. The owner can revoke access at any time at https://myaccount.google.com/permissions.
