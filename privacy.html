Privacy Policy

Hypothetical Capital Uploads · Last updated 30 October 2026

Hypothetical Capital Uploads uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Information is also handled under the Google Privacy Policy.

Who uses this tool

Hypothetical Capital Uploads is a private tool used only by the owner of the Hypothetical Capital YouTube channel (youtube.com/@HypotheticalCapital) to manage that one channel. It has no other users, no sign-up and no public interface.

What information is accessed

With the channel owner's permission (Google sign-in, OAuth 2.0), the tool uses the YouTube Data API and the YouTube Analytics API to access only the owner's own channel:

  • the channel's own videos, playlists and their details (titles, descriptions, tags, thumbnails, publish times);
  • comments the owner posts on the channel's own videos;
  • the channel's own aggregated YouTube Analytics reports (impressions, click-through rate, views, watch time, audience retention).

It does not access any other user's account, channel or data, and it does not collect personal information about viewers.

How the information is used

The tool uploads the owner's own videos, sets their details and publish times, posts a comment, and reads the channel's own analytics to improve titles, thumbnails and future videos. Nothing is used for advertising or profiling.

What is stored, and where

The only credential stored is the owner's OAuth refresh token, kept privately in the owner's own environment settings. Analytics figures for the channel's own videos may be kept in the owner's private project files to compare videos. No viewer personal data is stored.

Sharing with third parties

No information is sold, shared with or transferred to any third party.

Cookies

The tool does not place cookies or similar technologies on any device, and this website does not use cookies.

Revoking access

Access can be revoked at any time from the Google security settings page: security.google.com/settings/security/permissions.

Deletion

Stored API data is refreshed or deleted at least every 30 days. If access is revoked, or on request to the contact below, the stored token and any stored API data are deleted within 7 days.
